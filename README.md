# Card Validator Frontend

A simple frontend interface for the Card Validator API.

## What it does

Accepts a card number input, sends it to the Card Validator API, and displays whether the card number is valid or not.

## Live Demo

API: https://card-validator-7bzt.onrender.com

## Running Locally

No build tools or dependencies needed. Just open the file directly:

```bash
open index.html
```

Or double click `index.html` in your file manager.

> Make sure the API server is running on `http://localhost:3000` if testing locally.
> Update the fetch URL in `index.html` accordingly.

This frontend connects to the Card Validator API.
